**INTRODUCTION**

This repository is for our final project for the fall 2026 ASTR 519 course. Our project goal is to confirm whether the rotation periods of stars in the Oceanus Cluster are consistent with a cluster age of ~500 Myr. We will do this by:

  (i) measuring rotation periods for likely members using public time-domain surveys 
  
  (ii) comparing the period-color sequence against a reference cluster of similar age (e.g., Praesepe or Hyades)
