# Rotation-Periods-for-Oceanus-ASTR519

## Tasks ##

1. Get Oceanus candidate stars from the catalog paper given to us.
2. Get colors for those stars by querying Gaia.
3. Get TESS or ZTF light curve data for those stars and make periodograms to find their rotation period.
4. Get rotation period and color data for reference star cluster.
5. Plot rotation period vs color for both Oceanus and reference cluster.
